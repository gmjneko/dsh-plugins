# dsh-plugins

个人使用的 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）插件集合。

| 插件 | 说明 | 来源 |
| --- | --- | --- |
| [dsh-animation-enhance](dsh-animation-enhance/) | 会话步骤展开/收起、账号菜单、设置面板、界面切换的 豆包网页版 风格动效| 本仓库 |
| [dsh-font-enhance](dsh-font-enhance/) | 调整界面基础字重的轻量增强 | 本仓库 |
| [dsh-mermaid](https://github.com/MrmoLabs/dsh-mermaid) | 把 Markdown 里的 Mermaid 代码块渲染成可交互 SVG（代码/图表切换、全屏、导出 SVG） | **Git Submodule** → [gmjneko/dsh-mermaid](https://github.com/gmjneko/dsh-mermaid)（上游 [MrmoLabs/dsh-mermaid](https://github.com/MrmoLabs/dsh-mermaid)） |

（其中 dsh-mermaid 放我自己Fork的仓库链接仅作为备份用，原版仓库在 [dsh-mermaid](https://github.com/MrmoLabs/dsh-mermaid) ）
